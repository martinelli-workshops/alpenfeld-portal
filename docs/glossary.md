# Glossary

| Term | Definition | Avoid |
|---|---|---|
| Buyer | An employee of a Business Customer who uses the portal to find products, submit Orders, request quotes, and initiate returns. | Purchaser |
| Business Customer | A business account that buys tools, fasteners, or workshop supplies from Alpenfeld and whose employees use the portal. |  |
| Contract Price | The customer-specific price for a Product, maintained in the ERP and copied to the portal. | List price |
| Customer Service | An Alpenfeld employee role that supports customers with Orders and handles Return Requests. |  |
| ERP | Alpenfeld's system of record for Contract Prices, Stock, order processing, and invoices. |  |
| Order | A Buyer's submitted request to purchase Products from Alpenfeld. |  |
| PIM | Alpenfeld's system of record for Product data and images. |  |
| Product | A tool, fastener, or workshop supply offered by Alpenfeld. | Item |
| Purchasing Manager | A Business Customer employee who approves Orders above the company's limit and manages its Buyers. |  |
| Quote Request | A Buyer's request for a quote, typically for a large quantity, that a Sales Representative answers. |  |
| Return Request | A Buyer's request to return a purchase, submitted through the portal for Customer Service to handle. |  |
| Sales Representative | An Alpenfeld employee who answers Quote Requests and looks after key accounts. | Salesperson |
| Stock | The available quantity of a Product, maintained in the ERP and copied to the portal. | Inventory |
