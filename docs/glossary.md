# Glossary

| Term | Definition | Avoid |
|------|------------|-------|
| Business customer | A company that purchases products from Alpenfeld Supply through the portal. | |
| Buyer | An employee of a business customer who searches for products and places orders. | |
| Purchasing Manager | An employee of a business customer who approves qualifying orders and manages that customer's buyers. | |
| Sales Representative | An Alpenfeld Supply employee who responds to quote requests and supports key accounts. | |
| Customer Service | An Alpenfeld Supply role that handles return requests and helps customers with their orders. | |
| Product | An item in the Alpenfeld Supply catalog that a business customer can purchase. | |
| Contract price | The price for a product that applies to a particular business customer. | |
| Approval limit | The order total above which a business customer's Purchasing Manager must approve the order. | |
| Stock | The quantity of a product recorded as available by the ERP. | |
| Order | A business customer's request to purchase one or more products. | |
| Quote request | A buyer's request for pricing on a large quantity of products. | |
| Return request | A buyer's request to return products from an order. | |
| PIM | The external system that supplies product data and images to the portal. | |
| ERP | The external system that supplies contract prices and stock and processes orders and invoices. | |
